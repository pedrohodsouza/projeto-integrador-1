# 🎨 Identidade Visual: CidadeLimpa (Padrão Paulista)

Este documento define a paleta de cores e o estilo visual do sistema, baseado na identidade cromática do estado de São Paulo.

## 🎨 Paleta de Cores (The São Paulo Palette)

| Cor | Hexadecimal | Uso Recomendado |
| :--- | :--- | :--- |
| **Vermelho Alerta** | `#e11d48` | Botões principais, ícones de atenção e destaque da logo. |
| **Preto Profundo** | `#0f172a` | Navbar, cabeçalhos secundários e textos principais. |
| **Cinza Urbano** | `#64748b` | Textos auxiliares e bordas suaves. |
| **Cinza Gelo** | `#f1f5f9` | Fundos de página e áreas de contraste. |
| **Branco Puro** | `#ffffff` | Cards, fundos de formulários e texto sobre cores escuras. |

## 📐 Diretrizes de Design

1.  **Contraste Forte**: Utilizar o Vermelho apenas para ações importantes (CTAs) e a Logo, contrastando com o fundo Branco ou Cinza Gelo.
2.  **Tipografia**: Continuaremos com a fonte **Inter**, que é moderna e legível. Pesos: 700 para títulos, 400 para corpo.
3.  **Bordas e Sombras**: Usar `border-radius: 8px` para um visual moderno e sombras sutis (`box-shadow`) para dar profundidade aos cards de denúncia.
4.  **Navbar Escura**: A barra de navegação será preta (`#0f172a`) para transmitir autoridade e permitir que a logo vermelha e branca se destaque.

## 🖼️ Logotipo
O conceito visual da logo é **Cidade<span>Limpa</span>**, onde o "Limpa" assume o Vermelho Alerta.
